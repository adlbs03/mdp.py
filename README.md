    # Safe.Password
    #### Video Demo:  https://youtu.be/Q28roYGxfJc?si=6_cppehV-TTBWg6q
    #### Description: This mini python script allows you to put a safe an ultra unique Password.
        How to use it ? Very simple, you write in the command line : python3 project.py
        You have to put a password, with some requirements (you're gonna see if it's okay or not)
        And then the script output a new password completely secret and unique based on secrets/random python library
        You can see the old and the new password in your history.txt
